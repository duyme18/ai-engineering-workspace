# ADR-0007: Flyway for database migrations

- Status: Accepted (2026-10-15)
- Date: 2026-10-14
- Milestone: M0 (implemented in M1)

## Context

The schema evolves every milestone. It must be versioned and reproducible in local/test/CI/prod,
and never generated by Hibernate (`ddl-auto`) outside throwaway experiments.

## Decision

Use **Flyway** with plain SQL migrations in `backend/src/main/resources/db/migration`.
Set `spring.jpa.hibernate.ddl-auto=validate`. Applied migrations are never edited.

## Alternatives considered

- **Liquibase** — DB-agnostic changelogs and rollbacks; more ceremony; we only target PostgreSQL.
- **Hibernate `ddl-auto=update`** — non-deterministic, unsafe for production. Rejected.

## Consequences

- \+ Plain SQL = full access to PostgreSQL features (CHECK constraints, pgvector, HNSW indexes).
- \+ `validate` catches entity/schema drift at startup.
- − No automatic down-migrations: fixes are forward-only (a new migration).
